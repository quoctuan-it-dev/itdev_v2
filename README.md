# Website Cá Nhân

 Giới thiệu

Đây là website cá nhân được xây dựng bằng HTML và CSS nhằm giới thiệu thông tin cá nhân, kỹ năng, dự án, thư viện ảnh và thông tin liên hệ.

 Chức năng
- Trang chủ
- Giới thiệu bản thân
- Thông tin cá nhân
- Kỹ năng
- Dự án
- Thư viện ảnh
- Trò chơi lật thẻ ghi nhớ
- Trang liên hệ
- Menu điều hướng 3 gạch
- Giao diện responsive trên máy tính và điện thoại

 Công nghệ sử dụng

- HTML5
- CSS3
- SVG
- Responsive Web Design

 Giao diện

Website sử dụng tông màu xanh navy, xanh dương và vàng làm màu chủ đạo.
